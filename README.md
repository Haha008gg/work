# 智能简历生成器 - Chrome插件

## 项目介绍
智能简历生成器是一款强大的Chrome浏览器插件，专为求职者设计。它能够根据招聘信息自动生成量身定制的专业简历，帮助用户提高求职效率和成功率。插件利用AI技术分析招聘要求，生成符合职位需求的个性化简历Markdown内容，并支持在线生成。

## 主要功能
- **智能简历生成**：基于招聘信息自动创建匹配的专业简历
- **个性化定制**：根据用户提供的个人信息生成个性化内容
- **一键导出**：将生成的简历直接导出为Word文档
- **数据本地保存**：自动保存用户输入的招聘信息和个人资料
- **内容自动保存**：保存用户粘贴的招聘信息，切换页面后返回不会丢失
- **进度提示**：生成简历过程中显示处理进度，让用户了解当前状态
- **文件位置快捷访问**：一键打开文档保存位置，方便用户查找和管理
- **简洁界面**：用户友好的操作界面，简单易用

## 如何安装
1. 打开Chrome浏览器，在地址栏输入: chrome://extensions/
2. 打开右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择包含这些文件的目录

## 如何使用
1. 点击Chrome工具栏中的插件图标打开弹出窗口
2. 首先在设置中输入您的OpenAI API Key (这是必需的)
   - 点击插件弹出窗口中的设置按钮
   - 在设置页面输入您的API密钥
   - 点击保存按钮
3. 填写您的个人信息（姓名、联系方式等）
4. 复制和粘贴招聘信息到文本框（内容会自动保存，切换页面后返回不会丢失）
5. 点击"生成简历"按钮（处理过程中会显示进度提示）
6. 生成后，您可以查看生成的简历内容
7. 点击"免费生成"按钮可直接跳转到mujicv.com网站，无需先生成简历
8. 您也可以使用"一键复制"功能复制简历内容

## 技术架构
- **前端**：HTML, CSS, JavaScript
- **API集成**：SiliconFlow API (使用deepseek-ai/DeepSeek-R1模型)
- **文档生成**：docx.js库用于创建Word文档
- **数据存储**：Chrome Storage API用于本地数据保存

## 文件结构
- **manifest.json**: 插件配置文件，定义插件的基本信息、权限要求和资源引用。包含插件版本、名称、图标路径以及后台脚本和内容脚本的配置。
- **popup.html/js**: 
  - **popup.html**: 弹出窗口的HTML界面，提供用户交互的主要入口，包含表单输入区域和操作按钮。
  - **popup.js**: 弹出窗口的核心功能实现，负责处理用户输入、保存数据、发送API请求、显示生成进度，以及触发简历下载功能。实现了招聘信息的自动保存和恢复功能。
- **background.js**: 后台常驻脚本，在插件生命周期内持续运行。负责处理API调用、简历生成逻辑、Word文档创建，以及文件系统操作。通过消息传递机制与popup.js通信，处理异步任务。
- **options.html/js**: 
  - **options.html**: 设置页面的HTML界面，提供API密钥配置和默认个人信息设置的表单。
  - **options.js**: 设置页面的功能实现，负责保存和加载用户配置，包括API密钥和个人信息的本地存储管理。
- **docx.js**: 第三方库，用于创建和格式化Word文档。提供了将简历内容转换为标准.docx格式的功能，支持文本样式、段落格式和文档结构的定制。
- **styles.css**: 样式表文件，定义插件所有界面的视觉样式，包括布局、颜色、字体、按钮样式和响应式设计等。确保插件具有一致的用户体验和美观的界面。
- **images/**: 包含插件各种尺寸图标的文件夹，用于在Chrome浏览器的不同位置显示：
  - **icon16.png**: 16x16像素图标，用于扩展管理页面
  - **icon48.png**: 48x48像素图标，用于Chrome网上应用店
  - **icon128.png**: 128x128像素图标，用于安装和更高分辨率显示

## 隐私说明
- 所有个人信息和招聘数据仅存储在本地浏览器中
- API调用通过用户提供的个人API密钥进行，数据不会被插件开发者收集
- 生成的简历文档保存在用户本地设备上

## 注意事项
- 此插件需要SiliconFlow API密钥才能工作
- 使用的AI模型是deepseek-ai/DeepSeek-R1
- 生成的简历仅作为参考，建议用户根据实际情况进行适当修改
- 插件在Chrome浏览器环境下运行，其他浏览器可能不兼容
- 当生成进度停在90%时，可能用时过长，请耐心等待（生成期间不要离开UI界面）。一般不超过5分钟
